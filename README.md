# PROVES Software Recruiting

Slides for recruiting software engineers to work on PROVES flight software with F Prime.

To start the slide show:

- Install [Nix](https://nixos.org/download/) and [direnv](https://direnv.net/), then run `direnv allow` (or run `nix develop`)
- Run `npm install`
- Run `npm run dev`

Edit [slides.md](./slides.md) to see the changes. The Discord bar shown on every slide lives in [global-bottom.vue](./global-bottom.vue); set the invite link there.

To deploy updated slides to the GitHub site, push changes to `main`.
